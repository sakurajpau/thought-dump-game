# 気づきノート

セッションとセッションの間に、クライアントが気づいたことを日記のように書き、麻美さんがあとでまとめて返信するための Web アプリです。スマホのホーム画面に置いて、アプリのように使えます。

- **クライアント**：自分のノートだけを読み書きできます。ほかのクライアントのノートは見えません。
- **麻美さん**：クライアントの一覧で「未返信 ◯件」を確認し、まとめて返信できます。
- **記録**：書いた内容は、本人も麻美さんも後から書き換え・削除できません。そのまま相談記録として残ります。
- **アカウント**：麻美さんが作ってお渡しする方式です。知らない人が勝手に登録することはできません。

## 準備するもの

- Supabase のアカウント（無料で始められます）: https://supabase.com
- 公開場所（このリポジトリの GitHub Pages など）

## 設定の手順

### 1. Supabase のプロジェクトを作る

1. Supabase で「New project」を選びます。
2. **Region は「Northeast Asia (Tokyo)」** を選んでください（相談内容が日本国内のサーバーに保存されます）。
3. データベースのパスワードは、安全な場所に控えておきます。

### 2. データベースを設定する

1. 左メニューの「SQL Editor」を開きます。
2. `supabase/schema.sql` の中身をまるごと貼り付けて「Run」を押します。

### 3. 勝手に登録できないようにする

「Authentication」→「Sign In / Providers」で、次のように設定します。

- **Allow new users to sign up**：オフ
- Email のログイン：オン（最初からオンです）

### 4. 麻美さんのアカウントを作る

1. 「Authentication」→「Users」→「Add user」→「Create new user」を選びます。
2. メールアドレスとパスワードを入れ、**「Auto Confirm User」にチェック** を入れて作成します。
3. 「SQL Editor」で次を実行し、このアカウントをカウンセラーにします（メールアドレスはご自身のものに置き換えてください）。

```sql
update public.profiles
set role = 'counselor', display_name = '麻美'
where id = (select id from auth.users where email = 'asami@example.com');
```

ここで入れた `display_name` が、クライアントの画面で返信の差出人として表示されます。

### 5. アプリに Supabase をつなぐ

1. 「Project Settings」→「API」（または「API Keys」）を開きます。
2. **Project URL** と **anon（publishable）key** を `config.js` に貼り付けます。
   - anon key は公開して問題ない鍵です。誰が何を見られるかはデータベース側で制限しています。
   - **service_role（secret）key は絶対に貼らないでください。**
3. `config.js` の `CRISIS_NOTE`（クライアントの画面に常に出るお知らせ）も確認してください。連絡先の番号は、使う前に必ずご自身で確認してください。

### 6. 公開する

GitHub Pages を使う場合は、リポジトリの「Settings」→「Pages」で公開するブランチを選びます。公開後のアドレスは `https://<ユーザー名>.github.io/thought-dump-game/counseling-journal/` のようになります。

アプリのコードは公開されますが、相談内容は Supabase にだけ保存され、ログインした本人と麻美さんしか見られません。

## クライアントを迎えるとき

1. 手順4と同じ方法（Add user → Create new user、Auto Confirm User にチェック）で、クライアントのアカウントを作ります。役割の変更は不要です（最初からクライアントになります）。
2. セッションの中で、アドレス・メールアドレス・仮のパスワードをお渡しします。
3. クライアントは初回ログイン時に、麻美さんに表示される名前を決めます。仮のパスワードは「⋯」→「設定」から変えてもらいます。
4. ホーム画面への置き方
   - iPhone：Safari で開き、共有ボタン →「ホーム画面に追加」
   - Android：Chrome で開き、メニュー →「ホーム画面に追加」

パスワードを忘れたと連絡があったときは、「Authentication」→「Users」でそのクライアントを選び、新しいパスワードを設定してお伝えします。

## 知っておいてほしいこと

- **返信が届いても通知は出ません。** クライアントには「アプリを開くと返信が見られる」と伝えてください（通知は今後の追加候補です）。
- **無料プランの Supabase は、1週間ほど使われないと一時停止します。** 停止しても管理画面から再開でき、データは消えません。長く使う場合は有料プランを検討してください（自動バックアップも有料プランの機能です）。
- 相談内容を外部のサービス（Supabase）に保存することになるため、利用を始める前に、クライアントへ保存場所と扱い方を説明し、同意をもらっておくことをおすすめします。

## ファイルの構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面と動き |
| `config.js` | Supabase の接続先と表示の設定 |
| `supabase/schema.sql` | データベースとアクセス制限の設定 |
| `manifest.webmanifest` / `sw.js` / アイコン | ホーム画面に置くための設定（相談内容は端末に保存しません） |
